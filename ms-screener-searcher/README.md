# Screener Searcher

### Reference Documentation
Servicio para uso exclusivo del servicio ms-screener. Recibe un lote de consultas y devuelve un lote de resultados.
El objetivo de este servicio es proporcionar escalamiento horizontal para el screener. Cuantas más instancias paralelas existan de screener-searcher, más rápido será el procesamiento de screener
